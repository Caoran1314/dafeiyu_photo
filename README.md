# 大肥鱼相册

她会**记住你发过的照片**，并在聊到相关话题时主动发出来。

## 逻辑

```
你发图 → 存进相册 + 用你当时说的话做标签
              ↓
聊天时：她的话 + 你的话 vs 标签
              ↓
命中 ≥2 个词 → 65% 概率发
              ↓
每天 ≤2 张 · 同一张 7 天不重复 · 不沾边不发
```

## 心情影响

- 压力 ≥0.45（烦躁）→ 发图意愿 ×0.25
- 亲近 ≥0.62 → ×1.35

## 命令

| 命令 | 作用 |
|---|---|
| `/相册` | 看相册内容 |
| `/相册发 1` | 当场发一张 |
| `/相册忘了 1` | 删掉 |
| `/相册重置` | 清冷却（测试用） |

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enable` | false | 要手动打开 |
| `prob` | 0.65 | 命中后发图概率 |
| `min_score` | 2 | 命中几个词才算沾边 |
| `max_per_day` | 2 | 每天上限 |
| `cooldown_days` | 7 | 同一张冷却 |
